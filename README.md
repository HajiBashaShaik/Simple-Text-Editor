# Simple Text Editor (Python)

A simple text editor application developed using Python and Tkinter. It provides basic features to create, open, edit, and save text files through a graphical user interface (GUI).

## Features
- Create a new text file.
- Open existing `.txt` files.
- Edit text easily.
- Save text files.
- Simple and user-friendly GUI.
- File menu with New, Open, Save, and Exit options.

## Technologies Used
- Python
- Tkinter

## How to Run

1. Install Python on your system.
2. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
3. Open the project folder.
4. Run the Python file:
   ```bash
   python main.py
   ```
